01 · About the project

What is Mission Orion?

Description

Mission Orion is an interactive experience designed for children to discover the fascinating world of space exploration. Through activities, challenges, and adventures, they can learn about space in a fun and exciting way.

Problem

Many kids feel curious about the universe, yet they do not always have interactive and entertaining tools that let them explore how space works and how real space missions are carried out.

Main Objective

To ignite children's scientific curiosity through an interactive experience that empowers them to learn about space, unlock new knowledge, and become young space explorers.

Why It Matters

Space education can inspire new generations to take an interest in science, technology, engineering, and mathematics (STEM), nurturing creativity, imagination, and scientific thinking from an early age.

04 · The technology

The technology

WEBGL2

Single-File 3D Core

Self-contained HTML5 simulator powered by Three.js r128, Web Audio synthesis, live bilingual I18N, and 3D SDF silhouette collisions.

AI+SIM

NASA Physics & Robbie AI

Deterministic lunar/Martian survival physics paired with Groq AI (openai/gpt-oss-120b) scoped to NASA Space Apps datasets.

NATIVE

Rust · Android · Co-op P2P

Cross-platform wrappers for Windows (tao+wry WebView2 .exe) and Android (.apk), plus serverless WebRTC co-op multiplayer.

Architecture

Single-File Core (HTML5 + Three.js r128 + WebAudio)
  ├─ Web SPA       → Firebase Hosting (Browser)
  ├─ Windows .exe  → Rust Loopback + WebView2
  ├─ Android .apk  → Hardware-Accelerated WebView
  ├─ Robbie AI     → Groq REST API (NASA Scoped)
  └─ Co-op P2P     → Host Hub + WebRTC (PeerJS/ntfy)

Shared simulation logic runs identically across Web, Desktop, and Mobile.
